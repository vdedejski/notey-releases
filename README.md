# Notey — downloads

A bot-free meeting notetaker for macOS. It records the microphone and the sound
your Mac is playing as two separate tracks, transcribes them **on the device**,
and sends only finished text to an AI, only when you ask.

No bot joins your call. Nothing is uploaded to be transcribed.

## Download

The latest build is under [Releases](../../releases).

Requires **Apple Silicon** and a recent macOS. Every build here is signed with a
Developer ID certificate and notarized by Apple, so it opens without warnings.

## What this repository is

Downloads only. Notey's source is not published here.
